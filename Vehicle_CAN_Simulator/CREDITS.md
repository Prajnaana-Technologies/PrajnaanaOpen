**Note on python-can (LGPL-3.0)**

AI Vehicle CAN Simulator uses python-can version 4.6.1 as an
UNMODIFIED library. No changes have been made to it.

    Unmodified source: https://github.com/hardbyte/python-can
    Licence text     : see the LGPL-3.0 at
                       https://www.gnu.org/licenses/lgpl-3.0.html

The LGPL-3.0 requires that you be able to substitute your own
version of the library. Because this application is packaged with
PyInstaller, python-can is compiled into the frozen archive inside
AIVehicleCANSimulator.exe rather than sitting in a folder you can
edit.

You can therefore exercise that right as follows:

  1. Obtain the complete source of this application, which is
     published together with its exact build recipe
     (vehicle_sim.spec) and its pinned dependency versions
     (requirements.txt).

  2. Install your preferred version of python-can in place of
     4.6.1.

  3. Rebuild:   pyinstaller vehicle_sim.spec

This reproduces the application with your version of the library
substituted. If you cannot obtain the source, contact Prajnaana Technologies Pvt. Ltd. and it will be provided.
